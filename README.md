# Technical Tasks

This repository contains solutions to a set of technical assignment tasks covering software development, embedded systems, and electronics.

## Contents

### 1. Beach Vacation Weather Optimizer
A Python command-line application that helps choose the best city for a beach vacation. It fetches real weather forecast data for three cities, scores each one based on ideal Mediterranean summer beach conditions, and displays a ranked comparison with an interactive map.

→ See [Weather_optimizer](Weather.md) for setup and usage instructions.

### 2. Embedded C Code Analysis
A written analysis of a provided embedded C program that controls a DC motor on a microcontroller. Covers what the code does, how it behaves under specific conditions, and what problems it has.

→ See [C_code_analysis.md](Task2.md)

### 3. Electronics Circuit Analysis
A written analysis of a DC motor control circuit schematic. Covers the purpose of the circuit and the role of each major component.

→ See [electronics_analysis.md](Task3.md)
